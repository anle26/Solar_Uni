# Data Dictionary

## Raw Data (`data/raw/`)
These files contain the original, unmodified data collected from the solar power plants.
- **`Plant_1_Generation_Data.csv`**: Inverter-level power generation data for Plant 1 (DC power, AC power, daily yield, total yield).
- **`Plant_1_Weather_Sensor_Data.csv`**: Environmental sensor data for Plant 1 (ambient temperature, module temperature, irradiation).
- **`Plant_2_Generation_Data.csv`**: Inverter-level power generation data for Plant 2.
- **`Plant_2_Weather_Sensor_Data.csv`**: Environmental sensor data for Plant 2.

## Processed Data (`data/processed/`)

### Merged Data (`data/processed/merged/`)
- **`generation_weather_merged.csv`**: The combined dataset containing both generation and weather data, cleaned and resampled to the appropriate intervals.

### Machine Learning Results (`data/processed/ml/`)
- **`ml_predictions.csv`**: The expected vs. actual AC power predictions generated by the machine learning model.
- **`ml_predictions_VN.csv`**: The localized (Vietnamese) version of the ML predictions file.
- **`anomaly_detection_results.csv`**: Records flagged as anomalies (underperformance, sensor failures, inverter clipping) identified by the Isolation Forest model and rule-based logic.

### KPI Tables (`data/processed/kpi/`)
- **`daily_plant_kpi.csv`**: Key performance indicators aggregated at the daily plant level.
- **`inverter_kpi_table.csv`**: Efficiency and performance metrics aggregated at the inverter level.
- **`target_inverter_analysis.csv`**: Detailed analysis and tracking for specific targeted inverters.

## External Data (`data/external/`)
- **`User_Guide_V_21.0.pdf`**: External reference documentation (e.g., CEA guidelines or technical manuals) used to validate methodologies and domain logic.
